This project showcases an interactive Tableau dashboard built using the Sample Superstore dataset. The dashboard provides a complete overview of business performance through key KPIs, visual insights, and drill‑down analytics. It is designed to help stakeholders quickly understand sales trends, profit distribution, and regional performance.

✅ Key KPIs Included
- Total Sales
- Total Profit
- Profit Ratio
- Quantity Sold
- Sales by Category & Sub‑Category
- Profit by Region
- State‑wise Performance Map
- Monthly Sales Trend
- Top 10 Products by Sales
- Bottom 10 Products by Profit

📈 Dashboard Highlights
- Interactive filters for Category, Region, and Order Date
- Clean, business‑friendly layout using Tableau containers
- Dynamic charts including bar charts, line charts, maps, and KPI cards
- Insights into high‑performing and low‑performing products
- Visual storytelling to support data‑driven decisions

🔍 Insights Derived
- Technology category contributes the highest sales
- Office Supplies has high sales but lower profit margins
- The West region shows the strongest overall performance
- Several products consistently generate negative profit, indicating pricing or discount issues
- Sales show seasonal patterns with peaks during year‑end months

🛠 Tools & Technologies Used
- Tableau Desktop
- Tableau Public
- Sample Superstore Dataset (default Tableau dataset)
